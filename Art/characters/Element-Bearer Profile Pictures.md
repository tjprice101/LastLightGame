# Element-Bearer Profile Pictures

32 copy-ready generation prompts: exactly two portraits for each of the 16
Element-Bearers, depicting first acquisition/base (Evo.1) and Omnic (Evo.6).
These are new square profile portraits, not replacements for full-body unit art.
No images are generated, delivered, installed or automatically awarded by this pack.

## Profile-specific composition and identity contract

Use a fully covered, neutral human head-and-shoulders portrait with the original
compact anime/cel renderer and eyes-only face. The deliberately composed lower
portrait boundary is not a severed limb or accidentally cropped full-body image.
Omnic intimidation comes from authored regalia and layered elemental architecture,
never realistic anatomy, facial additions, a new costume theme or another identity.
Preserve base clothing simplicity; first acquisition does not inherit final armor.
No names, titles, metadata or written emblems belong inside the generated image.

The subject, all shown signature equipment, crowns, hair and effect tips must fit
inside the central 80% square with a continuous visible 10% solid-key safety margin
on all sides and corners. Pull back the complete portrait ensemble uniformly; do not
clip tips or erase signature details. Long weapons appear as complete compact
accompanying motifs beside the shoulders, retaining their functional shape rather
than extending off-frame. Human portrait proportions stay compact, not realistic.
The face is the primary readable focal point; architecture surrounds, never hides it.
The bust format intentionally translates the authored full-body Omnic ensemble into
portrait-scale architecture. It does not require greaves or a floating full-body pose.
Inspect actual generated pixels for correct identity, intact tips and margins;
prompt text and regression checks cannot guarantee model compliance.

Each block has one exact evolution-mapped character reference at `--sw 150`:
base uses Evo.1; Omnic uses Evo.6 from the
[shared guide](../guides/midjourney-character-style-prompt.md#character-form-style-references).
The complete signed owner URLs, including query parameters, are preserved.
These links may expire: obtain refreshed owner-supplied URLs if inaccessible;
never invent or silently substitute a reference. References guide rendering only:
do not copy reference costumes or colors. The character-specific subject palette
is authoritative; prismatic/opal means faceting within it, not extra rainbow hues.
Unwanted-color exclusions apply to the subject, never the contrasting key background.

Focused validation:
`python -m unittest discover -s tools -p test_profile_picture_art.py -q`.
The regression suite checks all 32 IDs against the live roster, exact reference
suffixes, palette/key exemptions, renderer/framing, the 380-word prose limit,
base simplicity and each bearer's authored signature/Omnic architecture.
