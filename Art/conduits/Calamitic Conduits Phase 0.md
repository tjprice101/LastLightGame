# Calamitic Conduits Phase 0

Nine reference-free Rise-authored annihilation machines. Visual mechanisms suggest the approved effects without effect text or numeric lettering. These extend, never replace, the [five installed Calamitic designs](Calamitic%20Conduits.md).

**All Phase 0 images in this pack were delivered and installed (D-441).** Originals, actual runtime mappings and reviewed keys/gaps/hashes are preserved by tools/intake_calamity_phase0_art.py and its provenance manifest. The proposed filenames and prompts below are generation history, not new commissions. Names, titles, rarity and mechanics are metadata outside image prose. Black/white primary and secondary colors, sharp saturated sparkling crimson accents; pearlescent prismatic sheen means bounded faceting, never extra hues. The green key is exempt from subject palette exclusions. Only portraits use the exact evolution-matched character references at --sw 400 for this owner-requested pack; historical packs remain unchanged.

## Export and intake

Portraits: transparent 960px canvas. Icons/items/emblem/Conduits: transparent 256px canvas, up to 224px reviewed content; emblem must read at small badge size beside an Element Medal. Preserve archived original PNG bytes and the recorded hashes, source-specific keys, enclosed gaps and facing under Art/provenance. Supplied alpha is authoritative; never key it again. Use the reviewed intake and runtime mapping rather than historical proposed names. No runtime background removal or missing-image URLs. Passing prompt tests is not visual approval or a guarantee that a signed reference URL remains available.

Regenerate: `python tools\build_calamitic_art.py`. Validate: `python -m unittest discover -s tools -p test_calamitic_art.py`; global: `python -m unittest discover -s tools -p "test_*.py"`.
