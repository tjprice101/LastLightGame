# Calamitic Master Conduits

Nine reference-free Master icons (D-442): three per Calamitic Element-Bearer. D-444 replaces architectural and household-object silhouettes with integrated colossal machines, following the original [Omnic machine batch](../creatures/Awaken%20the%20Machines.md). Ozriel uses armored shield reactors and suppression machinery; Ilvaris uses harmonic compressors, wind turbines and timing drives; Kaelith uses rotary harvesters, fracture accelerators and an eclipse engine. Foundation (D-443) for all Legendary, Omnic and Master Conduits: cosmic, ornate, resplendent machinery made by Let and Rise together, mechanical masterpieces that shimmer and shine in the light while staying true to the bearer's colors and element. Object-only machines, no figures. Effects live in docs/conduit-catalog.txt; the original 48 Masters are in [Master Conduits](Master%20Conduits.md).

**All nine Master images delivered and installed (D-448).** Originals and reviewed keys/gaps/hashes are preserved by tools/intake_calamitic_master_art.py. The prompts below are the generation record. Names, titles, rarity and mechanics are metadata outside image prose. Black/white primary and secondary colors, sharp saturated sparkling crimson accents; pearlescent prismatic sheen means bounded faceting, never extra hues. The green key is exempt from subject palette exclusions. Only portraits use the exact evolution-matched character references at --sw 400 for this owner-requested pack; historical packs remain unchanged.

## Export and intake

Portraits: transparent 960px canvas. Icons/items/emblem/Conduits: transparent 256px canvas, up to 224px reviewed content; emblem must read at small badge size beside an Element Medal. Preserve original PNG bytes under Art/source after delivery; record hashes, source-specific keys, enclosed gaps and facing under Art/provenance. Supplied alpha is authoritative; never key it again. No runtime background removal or missing-image URLs. Review dark/light backgrounds, thumbnail clarity, all tips and corners, opaque powers and per-form architecture before installation. Passing prompt tests is not visual approval or a guarantee that a signed reference URL remains available.

Regenerate: `python tools\build_calamitic_art.py`. Validate: `python -m unittest discover -s tools -p test_calamitic_art.py`; global: `python -m unittest discover -s tools -p "test_*.py"`.
