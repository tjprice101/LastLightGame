# Last Light — Character Art Midjourney Prompt Guide

For the new female fire greatsword starter, female grass bow starter, male water
spear starter, and three basic enemy prompts, see [Starter Art](Starter%20Art.md).
This guide remains the shared style reference.

Reference target: **compact gacha JRPG unit illustration**, matching the supplied pirate chibi reference, not a cinematic anime battle portrait. Use a rounded oversized head, tiny torso, short limbs, and approximately 2.5–3-head-tall proportions. The character must have **only eyes as facial features**: no nose, mouth, eyebrows, or other facial marks. Render with clean contours, crisp cel shading and smooth painted highlights, not gritty sketching. Use a **solid pure-white background** with no scenery, gradient, texture, or cast-shadow backdrop. Keep the entire character and weapon visible. Aim for the character itself to occupy roughly one third of the canvas height, while its weapon, flowing costume, and separate curling effects extend much farther around it. Leave white gaps between effects and a white margin around the whole illustration. Character renders use **4:3** (1:1 only if a square card asset is specifically needed).

---

## Core Master Prompt (copy/paste base)

```
full-body gacha JRPG unit illustration on a solid pure-white canvas, one small [CHARACTER DESCRIPTION], rounded oversized head, tiny torso and short limbs, 2.5 to 3 heads tall, eyes are the only facial features, entire character visible from head to feet at roughly one third of canvas height, ornate [WEAPON/PROP] much larger than the character with its entire silhouette visible, flowing costume with gold trim, separate curling [ELEMENT COLOR] magic ribbons framing the small figure, white gaps between the effects, generous white margin around the complete illustration, clean precise contours, crisp cel shading, smooth painted highlights, jewel-like saturated colors, compact decorative composition --ar 4:3 --niji 6 --s 100 --q 1 --no closeup, portrait, bust, cropping, nose, mouth, eyebrows, scenery, horizon, vignette, gritty texture
```

> Swap the bracketed segments per character. Keep the layout instructions first. Avoid adding "cinematic," "battle splash art," aggressive foreshortening, or full-frame flame backdrops: those can compete with the compact white-canvas composition.

### White-Space Rule for All Character Portraits

Keep a small but unmistakable solid-white border on all four sides, outside the outermost weapon, costume, and elemental effects, not just around the character's body. Add this wording before the parameters in any character prompt:

```
centered composition, a clear solid-white breathing margin on all four sides beyond the entire character weapon and effects, nothing touches the frame edges
```

Later evolutions need not all conceal the character or summon another figure. Fire emphasizes enveloping elemental vestments; water emphasizes readable action poses and increasingly magnificent spear designs; grass emphasizes expanding wings and aura. Any concealment is intentional overlap, not cropping. Keep the eyes and signature clothing recognizable (fire's red scarf, water's blue sash, grass's green neckerchief), the complete weapon readable, and white gaps within the effects.

## Elemental Character Evolution Lines

Each line has six stages and keeps the same hair, eyes, signature clothing motif, and weapon type throughout. Stage 1 is intentionally plain: simple clothes, one basic weapon, and almost no effects. Evolution changes the pose and dominant design feature, not the character's body size. Fire grows into an enveloping flame vestment; water develops increasingly dynamic spear techniques and weapon ornamentation; grass develops increasingly elaborate wings and luminous aura while its bow stays secondary. Apply the white-space rule above to every portrait, including the basic forms. Append `--sref <reference_image_url> --sw 400` using the approved chibi style reference to each prompt.

## Parameter Reference & Why

| Parameter | Value | Purpose |
|---|---|---|
| `--ar` | `4:3` | Wider frame gives the oversized costume/weapon/effects room to spread out so the character reads as genuinely small within the composition. Use `1:1` only when a square card/portrait asset is specifically required |
| `--niji 6` | — | Niji model is tuned for anime/illustration linework; far closer to gacha game art than default MJ model. Do not pair with `--style` tokens unless using Midjourney's own in-app niji style picker — typing `--style expressive`/`raw` etc. manually throws a "Style not compatible with niji 6" error. Leave `--style` off entirely for the default niji look |
| `--s` (stylize) | `100` starting point | Start lower while testing character layout or weapon anatomy; raise only after the silhouette and white margins are working |
| `--q` | `1` (max for niji 6) | Niji 6 only accepts `0.25`, `0.5`, or `1` — values like `--q 2` are invalid and will error |
| `--seed` | optional | Lock a seed once you find a result with the right line-weight/shading balance, then reuse it across new characters for consistency |
| `--cref` / `--cw` | optional | Use character reference on an approved hero to keep anatomy/proportions consistent across a whole roster |
| `--sref` | optional | Use style reference on one of the attached reference images (upload to Discord/Midjourney first) to lock the exact rendering style across all future generations |

### Recommended consistency workflow
1. Upload the supplied pirate chibi reference to Midjourney and append `--sref <reference_image_url> --sw 400` to the character prompt. Use the desired reference, not the rejected dark swordsman results.
2. To also guide composition, place the reference image URL at the beginning of the prompt as an image prompt. This can carry over pirate details; a style reference alone does not lock layout.
3. Generate variants and inspect the actual result: complete head-to-feet figure, eyes-only face, small body compared with weapon and effects, and white gaps around the illustration. Numerical proportions in the prompt are targets, not enforced measurements.
4. Once an output matches, note its `--seed` and reuse the approved style reference across the roster. Use `--cref <image_url> --cw 100` only when preserving the same character's identity.

## Negative Prompt / Things to Avoid

Character prompts above already include `--no`. Merge additional unwanted traits into that list rather than appending a second `--no` parameter:


## Quick Checklist Before Submitting a Prompt

- [ ] `--ar 4:3` included (use `1:1` only for square card assets)
- [ ] `--niji 6` included (no `--style` flag appended after it)
- [ ] Compact chibi proportions specified (approximately 2.5–3 heads tall, rounded oversized head, tiny torso, short limbs)
- [ ] Complete character contained within the frame; fire may conceal the body, water preserves readable action stances, and grass prioritizes wings and aura while retaining recognizable eyes and signature clothing
- [ ] Clear solid-white breathing margin on all four sides beyond the outermost weapon, costume, and effects; nothing touches the frame edges
- [ ] Weapon/costume/effects much larger than the character, with complete weapon visible and white gaps between effects
- [ ] Style anchor keyword cluster included (cel-shading, bold linework, gacha splash art, etc.)
- [ ] Character isolated on a solid pure-white background with no scenery, gradient, texture, or background shadows
- [ ] Eyes are the character's only facial features (no nose, mouth, eyebrows, or other facial marks)
- [ ] Unique color motif chosen for the character's elemental theme (flame=red/orange, void=purple/black, nature=green/gold, etc.) for roster variety
- [ ] Supplied target reference attached with `--sref`; actual output checked before locking the roster style

## Floating Gacha Weapon Showcase Prompts (3:2)

These standalone 3:2 images are **splotchy ink weapon concept art presented as an anime-game equipment reveal**, with black-and-white shading and identifiable material and theme colors. One ornate weapon floats unsupported in white empty space while painted metallic shimmers catch its edges. Keep the inky rendering on the weapon itself, but preserve its functional parts: swords have a grip, guard, and blade; firearm-style ranged weapons have a grip, trigger guard, receiver, barrel, and open muzzle. These are anatomy cues, not a request for realistic engineering or a sniper silhouette. Gold, rose-gold, pink, and wood tones appear on selected panels and ornamentation, not just hairline outlines. Keep a clear white margin outside the entire weapon and all effects.

> Check each result at thumbnail size: can you trace the complete weapon without mistaking ink or energy for a physical part? Reject results with merged ink clouds, detached ornamental pieces, or effects crossing the contour. The canvas texture belongs to the illustration, not to a physical support under the weapon.

For the god-slaying showcases, add believable depth rather than flat diagram shading: beveled metal, recessed engravings, reflective highlights, and cinematic light cast by the energy. Preserve visible ink blooms and broken brush edges instead of turning the result into a photograph. Energy ribbons may sweep around the weapon in depth, but leave the grip, barrel, muzzle, and outer silhouette readable. Keep the white backdrop and outer margins even at maximum energy.

### Midjourney Techniques for Readable Weapons and White Margins

1. **Put anatomy and framing first.** Name the weapon's parts before describing ornamentation or ink. Aim for the complete weapon and effects to occupy the central 70% of the canvas, with roughly 15% white padding on each side. These are compositional targets, not guaranteed measurements.
2. **Start at `--s 100` for anatomy; try `--s 200` for the cinematic showcases below.** Raise stylization only while the weapon remains readable; higher values can compete with literal instructions. Compare both settings with the same prompt and seed rather than assuming more stylization means more realism.
3. **Use different references for structure and style.** In Discord, place a clear image of the desired weapon silhouette at the beginning of the prompt to guide content and composition. Attach the approved inky artwork as `--sref <style_image_url> --sw 200`. Do not use a melee image as the structure reference for a ranged weapon. On the web, assign the uploads to Image Prompt and Style Reference respectively.
4. **Adjust image influence only when an image prompt is present.** Start with `--iw 1`; increase cautiously if the anatomy drifts, since the reference can also carry over colors and details. Image-weight ranges vary by model version. `--iw` does not control `--sref`.
5. **Recover cropped results with the Editor or Zoom Out.** Expand the canvas around a good result and request a solid-white background. Inspect the result for newly invented parts. There is no `--margin` or `--zoom` prompt parameter, and `--ar 3:2` alone does not ensure padding.

References: [Image Prompts](https://docs.midjourney.com/hc/en-us/articles/32040250122381-Image-Prompts), [Style Reference](https://docs.midjourney.com/hc/en-us/articles/32180011136653-Style-Reference), and [Editor](https://docs.midjourney.com/hc/en-us/articles/32764383466893).
