# Old Conduit System Catalog (state at commit d82015ba, 2026-11-07)

Purpose: exact record of what the OLD Conduits (equipment) did, so the design can be merged into the new Radiant system. Research only; nothing in the repo was modified.

How to read this: the live rule set at d82015ba is **"Phase Zero" (rules version 18, `phaseZeroStatsReady = true` in `src/content/phase-zero-stats.ts`)**. Ability text comes from the approved catalog `src/content/phase-zero-conduit-catalog.ts` (generated from `docs/conduit-catalog.txt`), which `redesignEffect()` (`src/content/conduit-redesign.ts`) returns whenever the flag is true. The older D-313 "redesign" descriptions in `conduit-redesign.ts` and the legacy `+50%/level` stat scaling in `conduits.ts:conduitBuffs` are **superseded** (reachable only when the flag is false, i.e. old tests); the ordinary ones are summarized in Appendix A for history. Stat packages quoted per Conduit come from the runtime tables `phaseZeroStaticBonuses` (`phase-zero-conduit-stats.ts`) and `omnicSelfStats` / `omnicSquadStats` (`omnic-conduit-stats.ts`), cross-checked against the ability text. Percentages are exactly as in the source; "pp" = percentage points.

Totals at d82015ba: **99 ordinary-slot Conduits** (10 Common, 15 Rare, 15 Legendary, 45 Omnic, 14 Calamitic) + **114 Master Conduits** (78 for 26 original bearers, 36 for 12 Moon/Sunshade bearers). (Docs such as `docs/conduits.md` still say "48 Masters / 147 total"; that is stale. The code and `docs/master-conduits.md` say 114.)

# 1. System rules

## 1.1 Slots, tiers, ownership (`src/content/conduits.ts`)
- Each Element-Bearer has **8 ordinary slots** (`conduitSlotCount = 8`; `validateConduitSlots`) plus **1 separate personal Master slot** (`MasterLoadouts`; Masters are character-specific, `validateMasterCharacter`, and are never upgradeable).
- No duplicates per character. **Omnic: max 4** of the 8 (`validateConduitSlots`, `conduitEquipReason` "Four Omnic limit"; Masters sit in their own slot and do not count). **Calamitic: max 5** (since D-435; older saves normalized read-only by `normalizeLegacyCalamiticSlots`).
- **Element locks:** only Omnic ordinary Conduits have an element (`conduit.element`); equipping needs a matching character element (`validateConduitElement`, "Element mismatch"). Common/Rare/Legendary/Calamitic are universal; the element shown in the catalog for them is a cosmetic "suggested thematic element" only. Masters belong to one named bearer.
- Captured Elemental-Devourers can use ordinary gear only (`equipped()` in `conduit-runtime.ts` ignores `masterConduit` when `unit.captured`).
- Rarity tiers low to high: Common, Rare, Legendary, Omnic (Masters are "Omnic (Master)"), Calamitic (Rise-built, above Omnic). The 45 ordinary Omnics = 20 original Machines Omnics + 25 "kit" Omnics converted from the old kit Conduits (D-176; IDs flagged in 2.4).
- Acquisition (docs, for context): Commons sold in the Store for Prismatica (prices in 2.1); Rare/Legendary/Omnic as Machines drops (Omnic 1% total from stage 75+; `docs/conduits.md`); Calamitic for 100 Calamitic Tokens each (`calamiticTokenPrice`; tokens from Calamity chests); Masters from the Machine's Master Chest (`masterChest.chance = .50` in `master-conduits.ts` at the stage `machineStageCount` boss; `docs/conduits.md` says 1% in one line, the code says 0.50: ambiguous) plus guaranteed picks in Calamity EX+Omnipotent chests.

## 1.2 Ranks / upgrade scaling (+0..+5)
- `conduitUpgradeCap = 5`. Cost per step (Broken Mechanical Components) = `[25,50,100,175,250]` x rarity multiplier `{Common 1, Rare 2, Legendary 4, Omnic 200, Calamitic 400}` (`conduits.ts: conduitUpgradeCosts`, `conduitUpgradeRarityMultipliers`; table in `docs/conduit-upgrades.md`). Totals to +5: Common 600, Rare 1,200, Legendary 2,400, Omnic 120,000, Calamitic 240,000.
- **Phase Zero rank formula (live):** every *beneficial percentage* in the effect text that is listed in `phaseZeroUpgradePercentages` (`phase-zero-conduit-upgrades.ts: phaseZeroUpgradedAbility`) becomes `base x (1 + 0.10 x level)`; +5 = 150% of base. It is applied by regex over each `N%` token by position; the last column of the 2.x tables gives the 0-indexed positions that scale.
- **Fixed (do not scale):** penalties (negative values), trigger thresholds (e.g. 450 Health, 75%/40%/50% Health lines), proc chances, durations/turn counts, extra-action counts, caps, flat `+N turns Skill Duration`, and all Master effects (`phaseZeroUpgradedAbility` throws for level != 0 on `master-*`).
- **Exceptions:** Stasis Reliquary chance = `10 + 2 x level` % (`stasisChancePercent`; 10..20%). Causality Funeral Engine Skill Efficiency = `50 + 2 x level` % (not 10% of base). Nullsong's positive +75% scales (to +112.5% at +5) but its -75% penalty and the 50/50 roll stay fixed. Glassroot Gimbal's 5% per 450 Health coefficient scales. Omnic **squad aura** stats scale `1 + 0.1 x level` (Master squad auras are fixed).
- Static stat implementation: `phaseZeroUpgradeMagnitude(base, level) = base > 0 ? base x (1 + 0.1 x level) : base` (`phase-zero-conduit-stats.ts`). Runtime conditional magnitudes use `magnitude()` in `conduit-runtime.ts`, which calls the same function with the equipped Conduit's saved level from `state.conduitUpgrades`.

## 1.3 Phase Zero stats and how Conduit stat bonuses aggregate
Ten stats (`phase-zero-stats.ts`): Health, Defense, Direct Attack (`damage`), Critical Damage Multiplier (`critMultiplier`), Critical Rate (`crit`), Elemental Gauge Capacity (`shatterCapacity`), plus four new ones: **Skill Power** (base 100%), **Skill Duration** (base +0 turns), **Skill Efficiency** (base 0%), **Elemental Gauge Gain** (base 100%). No level growth for the four new stats.

Aggregation (`applyPhaseZeroStaticBonuses`, `refreshConduitStats`):
- **Percent pool (multiplies the base stat):** Health, Defense, Direct Attack, Critical Damage Multiplier, Gauge Capacity. `result = base x (1 + sum of all percent bonuses)`; bonuses from several Conduits, role perks and Master/aura packages **add together first**, never multiply each other.
- **Additive pool (flat added to the base value):** Critical Rate, Skill Power, Skill Efficiency, Gauge Gain. `result = base + sum`. So +15% and +20% Skill Power = 135%, not 138% (contract text in `docs/conduit-catalog.txt`).
- **Skill Duration:** whole turns, added flat (never upgraded), floored; no global cap (D-382) but per-status caps apply (1.5).
- **Floors/caps:** every stat floors at 0 except Skill Efficiency; **Skill Efficiency capped at 50%**; Critical Rate may exceed 100% (excess becomes Elemental Crit chance); enemy Defense reduction caps at 50%, Defense-ignore ("pierce") at 75% (`nativeTargetDefense`, `conduitHitModifiers`).
- Role perks fold into the same pools (`role-perks.ts: roleBonuses`): Tank +50% Defense; Attacker +100% Direct Attack and +50% Skill Power; Support +50% Health and +25% Skill Power (plus Support heals the squad 4% max Health on Skills/Last Flare). Element Resonance (`element-resonance.ts`): 2 same-element bearers +15% Health; 3 same-element +25% Health and +5% Skill Power. Ascension (`docs/units-and-progression.md`): each ascended ability gets +50% Skill Power and +5 pp Skill Efficiency for that ability only.
- **Dynamic stats** recomputed in battle by `refreshConduitStats` (rules version 18): Master personal stats; Omnic/Master squad auras (summed per living wearer, including duplicate names; a dead source stops contributing); Clearwater (+Skill Power per other Oceanic squad member), Ruinselect (per defeated member), Phoenix Lifeforge (+Direct Attack while any enemy burns), Throne of the Lone Apostate (solo bearer), Horizon Heartcase (+Health/+Defense while Last Flare is blocked), Glassroot (Skill Power per 450 Health). Held Health is clamped to the new max and never healed by the change.
- Static bonuses are continuous, not per hit; Phase Zero bonuses never combine with legacy `applyConduitBuffs` bonuses.

## 1.4 Skill Power, Skill Duration, Skill Efficiency, Gauge Gain in play
(Cited: `conduit-runtime.ts: prepareConduitAction, conduitActionCost`, `battle.ts` ~lines 690-870, `docs/conduit-catalog.txt` "PHASE 0 - STAT CONTRACT".)
- **Actions:** Normal Attack ("light"), Skill 1, Skill 2, Last Flare ("ultimate"). Base Gauge costs 0 / 25 / 40 / 100 (`combat.ts: shatterGauge.costs`), base capacity 100. A Normal Attack gains +20 Gauge; each enemy hit taken gains +10 Gauge (`gains`, `incomingHit`). Skills themselves grant 0.
- **Skill Power** (`ctx.skillPower`) starts from the actor's Skill Power stat (+0.5 if that ability is ascended), then Conduit effects add to it **additively within the activation** (`ctx.skillPower +=` for Sentinel, Execution Orrery, Opal Indexer, Springwell, Siege Cantilever, Worldbreaker Drive, tokens such as Verdant/Covercharge/Fault Verdict, Choir-Array, ...) plus per-target `skillPowerBonus` (Eclipse Mantle, Sootwake, Secondbeat, Quarry/Fold masters). Damage = coefficient x `(skillPower + skillPowerBonus)` x `(1 + bonus)` x ..., where `bonus` is a *separate multiplicative* Direct-Damage layer (Worldbreaker Drive +65%, Parallax Relay +10% on Last Flare, Dawn Witness +200%, Causality +125%, Eclipse Mantle/Fault Verdict Last Flare bonuses). Skill Power also multiplies authored healing, Shield size and Burn/Weaken potency (`applyConduitBurn`, `applyConduitWeaken`, `nativeHeal`, `nativeShield`). It does **not** apply to Normal Attack (`skillPower = 1` for "light"), duration, Gauge rewards, action counts, crit chance or **Conduit-generated** strikes/heals/Shields (those use their own stated values).
- **Support Skill Power:** `supportPowerBonus` (Support perk, Rootbound Triage token) adds only to heal/Shield skills.
- **Skill Duration** adds whole turns to timed effects the Skill applies: Burn (`2 + clockExtension + skillDuration`, max 6, `battle.ts`), Weaken (`baseDuration 2 + skillDuration + 1 if Undertide`, max 6, `applyConduitWeaken`), and Vaelor's Resonance Cascade buff. Never to cooldowns, recovery, instant effects, revives, Shields (they last until broken) or delayed payouts. Sources: Opal Indexer (+1, debuff Skills only), Resonance Crucible (+1 static), World-Eater's Orrery (+3 static), Undertide Chronometer (+1 Weaken), Ember Coronation Iris (+1 Burn), Quiet Heaven Fanforge master.
- **Skill Efficiency** = percentage cut to Skill 1/2/Last Flare Gauge cost: `cost = max(floor, ceil(base x (1 - min(.5, efficiency))))`, floor 1 (Skills) and **70 for Last Flare** (`phaseZeroSkillCost`). So Last Flare can only go 100 to 70 (30% effective) although the cap is 50%; Skill 1 goes 25 to 13 and Skill 2 40 to 20 at the cap. Efficiency stacks additively with temporary tokens (Skythread, Storm Clock, Tempered Strike, Accord, Cover, Triage, Stormstep offers, Paradox Spindle, Undertide, Reliquary, Starvein, Execution Orrery). Target-dependent costs (Undertide) are evaluated against the selected target.
- **Gauge Gain** multiplies every positive incoming Gauge receipt (attacks, hits, Conduits), rounded once (`phaseZeroGaugeOffer`; `effectiveGaugeGain` also adds temporary bonuses: Starvein +10%, Crosswind/Vaelor +20-30%, Bruno Quarry Planet +25%). Conduit grants written "X% Elemental Gauge" restore X% of the recipient's own max capacity first, then Gain applies (`phaseZeroPercentageGaugeOffer`). Capacity adds room, not Gauge. Overflow transfers cannot re-transfer.
- **Cooldown / Recovery:** Last Flare makes the caster skip the next player turn ("Recovery", `actor.recoverThrough = round + 1`); captured units also have a cooldown. Conduits touching this: Causality Funeral Engine (no Cooldown/Recovery), Stillhour Carillon, Paradox Spindle, Horizon Heartcase (buffs while blocked by Gauge/Cooldown/Recovery), Throne of Borrowed Tomorrows (extra Skill actions).

## 1.5 Triggers, caps, stacking (runtime and contract)
General contract (`docs/conduit-catalog.txt` "GLOBAL DESIGN CLARIFICATIONS"), enforced in `conduit-runtime.ts`:
- **Attack Action** = a damaging Normal Attack, Skill 1, Skill 2 or Last Flare activation (not Burn or generated damage). Repeated impacts of one activation count once. Normal Attacks/Skills must be manually used to trigger equipment; Masters may also trigger off their bearer's native delayed effects.
- **Conduit-generated** strikes (`generatedStrike`: mitigated by `owner.damage / (owner.damage + Defense)`, min 1, consumes Shield, cannot crit), heals (`generatedHeal`: rounded, limited by missing Health, modified by `healingReceived`), Shields (`generatedShield`: size minus existing Shield unless additive) and Gauge (`generatedGauge/Percent`) **cannot trigger other Conduit procs or earn native resources**, and are not scaled again by Skill Power.
- **Once-per gates** are explicit per effect: once per round (Seraph Mirror, Pulse Trigger Pawl, Pressurecrest, Fault Verdict), once per Skill (Tension Governor, Meridian Inverter), once per Battle (Accord per ally, Phoenix Reactor; rescue/revive `rescueUsed` is shared across all rescue effects), Choir-Array 4 per encounter.
- **Next-action tokens** (`grantToken`/`token`): hold one copy per named Conduit per recipient; refresh instead of stacking; valid through `state.round + 1` (the rest of this player turn and the next); consumed by the next matching action; a multi-target grant hits each recipient once.
- **Caps:** Skill Efficiency 50%; Last Flare cost floor 70; Weaken strength max 50% (`Math.min(.5,..)`); Weaken/Burn duration max 6; enemy Defense reduction 50% total; Defense-ignore 75% total; Shield damage reduction (Pale Bulwark 50%, Bulwark of the Last Horizon 16.67%, Aegis-Engine 36.67%, all scaling) combined cap 80% (`absorbEnemyDamage`); non-Defense incoming damage reductions combine multiplicatively and cannot take a hit below 20% of its pre-reduction value (`conduitIncoming`: `Math.max(damage * .2, offered)`); spread Burn/moved Weaken cannot chain.
- **Shields:** every Shield lasts until broken (D-434). Skill/Last Flare Shields stack additively on repeat casts; Conduit Shields keep their stated sizing/refresh rules (Worldtree Heart replaces its previous Shield; Ouroboros/Phoenix/Pressurecrest "until broken"). Shield provenance (owner) is tracked per layer (`ConduitShieldLayer`), which Aegis Covenant, Leviathan Ward Loom, Tidebound Reflector and several Masters read.
- **Healing:** only effective healing counts for triggers (overhealing counts only where named: Worldtree Heart). "Lowest/most injured" means lowest HP ratio, then formation order.
- **Glossary** (`conduit-glossary.ts`): Burn = 25% of source Direct Attack per enemy phase for 3 phases unless stated; same-source reapply refreshes and keeps the stronger. Weaken = -25% enemy outgoing direct damage for the next enemy phase; the strongest active applies. Bonus Strike = extra Conduit hit. Global = all eligible targets on a side.
- **Rescue/revive:** once per recipient per Battle across all sources (Phoenix Reactor 35% Health with 0 Gauge; Accord leaves 1 Health; Worldseed master 35%).
- Battle limits reset with a new encounter, not on Settings or revival. Non-stat squad auras with the same name use only the strongest instance ("Multiple copies do not stack") but Omnic/Master *stat* squad packages sum per living wearer.

## 1.6 How Conduits connected to Skill 1 / Skill 2 / Last Flare
- `conduitActionTraits` classifies each activation as damage / healing / shield / debuff (native kits hand-coded per character; non-native by kit strengths). Many Conduits read these traits ("Skills that apply a Debuff", "Skills that heal or grant Shields", "damaging Skills", "Global damaging Skills"), so one Conduit behaves differently on Skill 1, Skill 2 and Last Flare depending on the bearer's kit.
- Action-specific Conduits: Skill 1 only (Sentinel Aperture); Skill 2 only (Execution Orrery); Last Flare only (Worldbreaker Drive, Parallax Relay +10%, Horizon Heartcase, Eclipse Mantle +45%, Rosefault Precision Sovereign +70%, Causality Funeral Engine, Storm Clock discount, Stillhour Carillon recovery, Ouroboros Shield, Throne of Borrowed Tomorrows); Skill 1 or 2 only (Pulse Trigger Pawl, Skythread Rudder, Stormstep Dynamo alternation).
- Gauge loop: Normal Attack (+20 Gauge) is the engine; Skills cost Gauge; Gain/Capacity/Efficiency and many "give allies X% Gauge" Conduits tune how fast Skills and Last Flare come online (see 3).
- Chains: "next Skill gets +X Skill Power/Efficiency" tokens link one ally's action to another's (Covercharge Drum, Verdant Covenant, Sootwake, Secondbeat Rack, Fault Verdict, Dawn Witness, Rootbound Triage, Tempered Strike Link, Stormstep Dynamo, Skythread Rudder, Storm Clock).

## 1.7 Master Conduit personal mechanics
- One per character (separate slot), only for the named bearer, fixed values, non-upgradeable, rarity "Omnic (Master)". Three alternatives per bearer ("-1/-2/-3" are alternatives, not ranks). Typical shape: **a personal stat package** (Health/Defense/Direct Attack/Skill Power/Skill Efficiency/Gauge Gain/Crit pp, in `omnicSelfStats`, applied through the same pools via the `master` argument of `applyPhaseZeroStaticBonuses`) **plus a modification of the bearer's native kit** (raise a native resource cap, add a rider to a named Skill/Last Flare, convert a native effect), and often a **squad-wide aura** (`omnicSquadStats`: all squad members get Health/Defense/Skill Power/Skill Efficiency while the bearer lives).
- Masters never give another character that kit; they "modify existing authored abilities" and never fabricate a missing native effect (`docs/conduit-catalog.txt`). Their generated follow-ups are excluded from proc chains. Master-specific Skill Power scaling is explicitly allowed (e.g. Neralis/Seravelle/Varkhel Shield masters scale with the bearer's Skill Power).
- The 36 Moon/Sunshade masters follow a fixed template (`moon-sunshade-masters.ts`): slot 1 = raises a native resource cap or coefficient, slot 2 = a Shield/heal/Defense/Skill Power rider, slot 3 = mostly a Gauge grant or Skill Efficiency rider; every one carries a personal stat line written as `+X% stat | +Y percentage points stat`.
- Masters appear in `masterConduits` (78 original-bearer entries + `moonSunshadeMasters` 36). `characterReleased` hides only `sunshadeCharacters`' masters from chests (docs say the 36 seasonal alternatives are "inactive").

## 1.8 Other carried rules
- Upgrade Max Level (D-306): one atomic spend, partial steps never skipped (`docs/conduit-upgrades.md`).
- Calamitic design rule: "one clear squad-changing mechanic, not long chains of conditions" (`docs/conduit-catalog.txt`).
- Rules version and gate: `conduitRulesVersion = 18` with phase zero on; saved holdings/levels are preserved across rules bumps.

## 3.2 Effects that made Skill 1 / Skill 2 / Last Flare choices more interesting

Ranked roughly by how much they changed what you press:
1. **Action-specific Skill Power:** Sentinel Aperture (Skill 1 +99%), Execution Orrery (Skill 2 +99%, +10% efficiency), Worldbreaker Drive (Last Flare +99% and all Attack Actions +65%). They make one slot the best button and give a reason to equip the matching Skill. Siege Cantilever and Worldbreaker Cannonade (+150% / +166.7% on Global/AoE Skills) reward pointing the right Skill at multiple enemies.
2. **Trait-gated Skill Power:** Opal Indexer (debuff Skills), Springwell Pump / Reliquary of Unending Mercy / Judgment Lens (heal-Shield or support Skills), Judgment Lens's +50% crit mult on damaging Skills. Skill 1 and Skill 2 often have different traits, so the Conduit set determines which is the "main" Skill.
3. **Alternation / sequencing:** Stormstep Dynamo (+30% Skill Power and +15% efficiency offer to the next ally when you alternate Skill 1 and Skill 2; a Normal Attack breaks it), Nullsong Transmission (50/50 swing per cast), Covercharge Drum / Verdant Covenant / Sootwake / Secondbeat (the next ally's Skill is boosted if yours damaged, healed or Burned first), Skythread Rudder and Storm Clock (efficiency tokens for the next Skill 1/2 or Last Flare). These turn the squad into a sequence puzzle rather than three independent bars.
4. **Gauge economy shaping:** Normal Attack Conduits (Twinpulse Bellows, Griffin Turbine, Kirin Cradle, Atlas Bastion, Skythread Rudder) make the +20-Gauge Normal Attack worth using; Gain/Capacity/Efficiency items change when a Skill 2 or Last Flare is affordable. Efficiency caps (50%, Last Flare floor 70) bound the build space.
5. **Last Flare economy:** Causality Funeral Engine (no Cooldown/Recovery, +125% damage, +50% efficiency), Horizon Heartcase (defensive stats while Last Flare is blocked), Stillhour Carillon and Paradox Spindle (value during Recovery), Throne of Borrowed Tomorrows (extra Skill 1/2 for allies who already acted). These make "when do I fire Last Flare" a real decision.
6. **Crit/conditional damage riders** (Dawn Witness: fail to crit, then next Attack Action gets +200% Direct Damage and +30% crit mult; Thunderbird Coil; Eclipse Mantle +45% Last Flare; Fault Verdict +70% Last Flare) reward particular sequences rather than raw stat size.
7. **Master mechanics** (1.7) are the deepest: they alter the bearer's own Skill 1 / Skill 2 / Last Flare behaviors (resource caps, extra riders, Gauge/Shield returns), so the same Skill reads differently with each Master.

## 3.3 Where effects were redundant or weakly differentiated
- **Static stat filler on Omnics.** Every ordinary Omnic and Master has an auto-assigned stat package from a small pool (Health, Defense, Direct Attack, Skill Power, Skill Efficiency, Gauge Gain, Crit) in `omnic-conduit-stats.ts`; many are only loosely related to the mechanic (e.g. big Direct Attack on a healer Omnic, Skill Power on Shield-only Conduits). The mechanic is the identity, the stats are padding, and they dominate raw power.
- **Stat-only Common/Rare/Legendary** (about 19 entries) are mostly interchangeable: the same Health / Defense / Direct Attack / Skill Power / Efficiency / Gauge numbers in different mixes. Vigil Core vs Immortal Vessel vs Calamitic Heartforge/Monolith are "big Health / Defense" in three price tiers.
- **Overlapping Skill Power Conduits:** Sentinel Aperture vs Execution Orrery vs Worldbreaker Drive (same +99%, different button); Siege Cantilever (+150% Global damaging Skills) vs Worldbreaker Cannonade (+166.7% skills hitting all enemies); Springwell Pump vs Reliquary of Unending Mercy vs Judgment Lens support clause (heal/Shield Skill Power three ways).
- **Gauge-sharing family:** Twinpulse Bellows, Griffin Turbine, Pulse Trigger Pawl, Meridian Inverter, Atlas Bastion, Leviathan Pump, Stillhour Carillon, Skythread Rudder, Secondbeat Rack and many Masters all "give allies X% Gauge", differing mostly in trigger. Gauge Gain scaling plus capacity percentages make the numbers hard to compare.
- **Heal-on-crit / heal-on-hit:** Verdict Caliper, Seraph Mirror, Lifeline Flywheel, Duplex Heart and Mending Valve are near-substitutes (small self/squad heals).
- **Stacking waste from caps:** Skill Efficiency beyond 30% is wasted on Last Flare (floor 70); beyond 50% for Skills. Weaken capped at 50%, Defense reductions at 50%/75%, Shield damage reduction at 80%, all non-Defense reductions floored at 20% damage; non-stacking auras ("multiple copies do not stack": Breach Pendulum, Citadel Spine).
- **Narrow categories:** Skill Duration (5 entries, only for timed-effect bearers) and Burn amplifiers (only for Burn bearers) are dead slots for most characters.
- **Duplicated "per-ally token" logic:** about 12 Omnics grant a one-copy "next Skill" token; the per-recipient refresh rules make several equivalent in practice.
- **Legacy design intent vs live:** the older D-313 designs (Appendix A) had more bespoke mechanics (damage reserves, cooldown pushes, Shield spill rules) than the live Phase Zero text, which converted many of them into Skill Power/Efficiency/Gauge statements. The unified stat set (Skill Power / Duration / Efficiency / Gain) is what made the roster compact and comparable; the cost is that many effects reduce to "+N% of the same four numbers".

## 3.4 Ambiguities / undeterminable items
- Master chest drop chance: code `chance: .50`, docs mention 1% (D-201 line); not resolved here.
- Docs report "48 Masters / 147 total" in several places; code defines 114 Masters (78 + 36). The 36 Moon/Sunshade masters' availability depends on `release-visibility.ts` (only `sunshadeCharacters` hidden); docs call the seasonal alternatives "inactive".
- Static stat packages for ordinary items are in two tables (`phaseZeroStaticBonuses` and `omnicSelfStats`); where ability text and tables could disagree I found none. Dynamic additions (Heartcase +10% Defense, Glassroot, Clearwater, Ruinselect, Emberlife, Lone Apostate) are in code only.
- Percent scaling positions come from `phaseZeroUpgradePercentages`; the "+250% Critical Rate" style numbers in Calamitic text come from the same table, not independently checked beyond text parity.
- I did not read the large Master native-kit code paths (`native-kits.ts`) line by line; Master effect text and stat packages are authoritative as listed but their precise native-resource interactions depend on kit code not summarized here.
- Whether test expectations match shipped behavior: `docs/conduit-behavior-matrix.md` claims 789 passing scenarios at the time; not re-run.
